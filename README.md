# Automated Threat Monitoring & Response

## Описание проекта

Данный проект реализует инструмент автоматизированного мониторинга и реагирования на угрозы информационной безопасности.

Скрипт анализирует различные источники данных, выявляет потенциальные угрозы и формирует отчёт с визуализацией результатов.

Проект разработан в рамках итогового задания по дисциплине **«Программирование на Python»**.

Основная задача программы — объединить несколько источников данных безопасности, выполнить анализ событий и сгенерировать отчёт об обнаруженных угрозах.

---

# Основные возможности

Скрипт выполняет следующие функции:

* анализ событий **Windows Security Logs**
* анализ **DNS-запросов**
* анализ **HTTP-трафика**
* анализ логов **IDS/IPS Suricata**
* проверка доменов через **VirusTotal API**
* получение информации об уязвимостях через **Vulners API**
* автоматическое выявление подозрительных событий
* имитация реагирования на угрозы
* формирование аналитического отчёта
* построение графиков безопасности

# Архитектура решения

Работа программы состоит из нескольких этапов.

## 1. Загрузка логов

Загружаются:

* demo logs

  * Windows events
  * DNS logs
  * HTTP logs
* Suricata logs (`eve.json`)

## 2. Анализ событий

Программа выявляет:

* неудачные попытки входа
* очистку журнала аудита
* создание новых учётных записей
* подозрительные DNS-запросы
* массовые DNS-запросы
* использование инструментов сканирования (sqlmap, Nikto)
* сетевые атаки из логов Suricata
* аномальные сетевые потоки

## 3. Threat Intelligence

Дополнительно используются внешние источники угроз:

### VirusTotal API

Проверка доменов на наличие вредоносной активности.

### Vulners API

Получение информации об известных уязвимостях и их CVSS-оценке.

## 4. Реагирование

При обнаружении угрозы выполняется:

* вывод предупреждения
* имитация блокировки IP-адреса

Реальное блокирование не выполняется, используется демонстрационная модель реагирования.

## 5. Формирование отчётов

После анализа создаются:

* CSV отчёт
* JSON отчёт
* графики аналитики

```
matplotlib

```

---

# Настройка API-ключей

Для безопасности API-ключи **не хранятся в коде**.

Создайте файл `.env`:

```
VT_API_KEY=your_virustotal_api_key
VULNERS_API_KEY=your_vulners_api_key
```

Файл `.env` добавляется в `.gitignore` и **не публикуется в репозитории**.

# Запуск программы

Запустите скрипт:

```
python main.py
```

После запуска программа:

1. загрузит логи
2. выполнит анализ событий
3. проверит домены через VirusTotal
4. получит информацию об уязвимостях
5. сформирует отчёт
6. построит графики
